## PROJETO

Solução desenvolvida para o desafio técnico front-end do processo seletivo da **APCD — Associação Paulista de Cirurgiões-Dentistas**.

O desafio consistiu em transformar um protótipo de página de formulário, desenvolvido no Figma, em uma interface web funcional, responsiva e visualmente fiel à proposta original.

O projeto teve como foco a aplicação prática de fundamentos de **HTML, CSS e JavaScript**, considerando aspectos como estrutura semântica, adaptação para diferentes dispositivos, interatividade e organização do código.

Além de representar uma etapa importante da minha evolução técnica, este foi o projeto que contribuiu diretamente para minha aprovação no processo seletivo e para a conquista da vaga de **Assistente Programador Web**.

🌐 [Acesse o projeto](https://lvcascouto.github.io/desafio-frontend/)

## FUNCIONALIDADES

- **Fidelidade ao protótipo** — implementação do layout com base no design desenvolvido no Figma
- **Design responsivo** — adaptação da interface para diferentes tamanhos de tela
- **Formulário interativo** — alteração do estado do botão após o envio
- **Feedback visual de envio** — atualização do texto do botão para “Enviado”
- **Reativação automática** — botão reativado após 1 minuto, sem necessidade de recarregar a página
- **Microinterações** — aplicação de estados visuais para melhorar a experiência de uso
